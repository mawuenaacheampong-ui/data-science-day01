
# Day 2: Data Structures and Algorithmic Thinking

## What I learned
- Lists store ordered collections and allow duplicates.
- Tuples group values that should not be changed item by item.
- Sets store unique values.
- Dictionaries connect keys to values.
- Linear search checks items one at a time.
- Binary search repeatedly halves a sorted search range.
- Big-O describes how work grows as input size increases.
- A set and a list can work together to remove duplicates
  while preserving first-occurrence order.

## Practical work completed
- Counted orders by status.
- Identified unique customer IDs.
- Implemented linear search.
- Implemented binary search.
- Removed duplicate IDs while preserving order.
- Wrote automated tests.

## Complexity notes
Linear search:
Time O(n), extra space O(1).

Iterative binary search:
Time O(log n), extra space O(1).

Order-preserving duplicate removal:
Expected time O(n) with average-case set lookups,
extra space O(n).

## Limitations
Binary search requires sorted input.
The search implementation assumes random-access data.
The example customer IDs and order statuses are synthetic.
