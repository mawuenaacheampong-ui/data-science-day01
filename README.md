
# Day 1: Python Revenue Calculator

## Project overview

This project calculates gross item revenue using Python.
It is my first practical exercise in my data science
and analytics learning journey.

## Business question

How much gross item revenue is generated from selling
a given quantity of a product at a given unit price?

## Formula

Gross item revenue = Quantity × Unit price

## Tools used

- Python
- VS Code
- Git
- GitHub
- unittest

## How to run

Run the calculator:

    python revenue_calculator.py

Run the automated tests:

    python -m unittest -v

## Data validation

The function checks for:
- Missing values
- Non-numeric inputs
- Negative quantities and prices
- Non-finite numbers

## Limitations

The calculator estimates gross item revenue only.
It does not account for discounts, refunds, taxes,
shipping, product costs or profit.
